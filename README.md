# Оно тебе надо

Проектная работа 1 спринта курса «Фронтенд-разработчик» в Яндекс Практикуме.

Одностраничный сайт аукциона вещей, в которые никто не верил: фильм режиссёра, бросившего киношколу, «Улисс» Джойса и картина Кандинского.

## Что сделано

- семантическая разметка: header, main, section, article, nav, address, footer
- подключены шрифты Raleway через `@font-face`
- шапка, раздел «Об аукционе» и подвал свёрстаны на гридах
- карточки лотов — флексбокс с переносом и `gap`
- полупрозрачный оверлей на обложке и карточках через `position: absolute`

## Технологии

- HTML5
- CSS3 (Flexbox, Grid)
- Git
